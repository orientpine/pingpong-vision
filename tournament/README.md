# Tournament app

The scoreboard half of PingPong Vision: brackets, scores, referee, spectator and TV screens, all on one address with the camera app at `/vision/`.

Install and use it from the main README at the top of this repository ([English](../README.md#tournament-and-pin), [한국어](../README.ko.md#대회와-pin)).

Run alone for development:

```bash
PORT=8792 DATA_DIR=/tmp/pp bun server.js
bun test
```
